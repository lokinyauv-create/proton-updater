Маленька програма для Linux, яка **сама стежить за новими версіями GE-Proton (і proton-rtsp)** і **перемикає в Steam вибрані ігри** на нову версію. Зроблена, бо VRChat на Linux вимагає свіжого Proton, а міняти його вручну після кожного релізу — набридає.

A small Linux tool that watches for new GE-Proton (and proton-rtsp) releases, installs them and switches the Steam games you choose to the new version.

## Що вона вміє

- Раз на 12 годин перевіряє нові релізи (таймер systemd, перевірка кожні 30 хв).
- Качає **лише з офіційних GitHub-релізів авторів** і **перевіряє sha512**. Якщо сума не збігається — не ставить.
- Ставить у `~/.local/share/Steam/compatibilitytools.d/`.
- Переключає Proton вибраних ігор у Steam (`config.vdf` → `CompatToolMapping`).
- Можна додати **будь-яку гру** зі Steam і вибрати **будь-яку попередню версію** (закріпити її).
- Кнопка **«Звідки це?»** — показує автора, репозиторій, сторінку релізу, адресу завантаження й контрольну суму.
- Кнопка **«Перезапустити Steam»** — закриває Steam, застосовує зміну, запускає знову.
- Прибирає старі версії (лишає 2 найновіші кожного джерела і ті, що використовуються).

## Джерела

| Ключ | Що | Автор / репозиторій |
|---|---|---|
| `ge` | GE-Proton | [GloriousEggroll/proton-ge-custom](https://github.com/GloriousEggroll/proton-ge-custom) |
| `rtsp` | Proton-GE RTSP (латки відео для VRChat) | [SpookySkeletons/proton-ge-rtsp](https://github.com/SpookySkeletons/proton-ge-rtsp) |

Це проєкти інших авторів; ця програма лише завантажує їхні релізи. Додати своє джерело — рядок у словнику `SOURCES` у `protonupd.py`.

## Як це працює

1. `proton-updater run` запускається таймером. Спершу застосовує відкладені перемикання, потім (якщо минуло 12 год) питає GitHub API про релізи кожного джерела.
2. Для кожної гри зі списку обирає потрібну версію: закріплену або найновішу. Качає архів, звіряє sha512, розпаковує в `compatibilitytools.d`.
3. Steam перезаписує `config.vdf` при виході, тому **змінювати файл можна тільки коли Steam закритий**. Якщо Steam працює — зміна відкладається, програма показує сповіщення; щойно Steam закрито, таймер застосує перемикання. Перед записом робиться копія `config.vdf.bak-protonupd`.
4. Конфіг програми: `~/.config/proton-updater/config.json`.

Вікно — на PySide6; ядро (`protonupd.py`) працює і без нього: `proton-updater status | check | run | restart | install ДЖЕРЕЛО ВЕРСІЯ | set APPID ДЖЕРЕЛО [ВЕРСІЯ]`.

## Встановлення

Потрібні: Linux, Steam (нативний, `~/.local/share/Steam`), Python 3.11+, PySide6 (для вікна), `notify-send` (для сповіщень), systemd користувача.

```bash
git clone https://github.com/lokinyauv-create/proton-updater
cd proton-updater
./install.sh
```

Скрипт створює команди `proton-updater` і `proton-updater-gui`, ярлик у меню та таймер `proton-updater.timer`. За замовчуванням стежить за VRChat (`438100`). Видалення: `systemctl --user disable --now proton-updater.timer` і прибрати файли з `~/.local/bin`, `~/.config/systemd/user`, `~/.local/share/applications`.

## Обмеження (чесно)

- Перевірено на Fedora 44 + KDE Plasma (Wayland) + нативний Steam. Flatpak-Steam не підтримується.
- Логіку перемикання версії в `config.vdf` перевірено на копії файлу; реальне автоперемикання на новий реліз ще чекає першого нового релізу.
- Змінює `config.vdf` текстовою заміною, без повного парсера VDF.
- Не обходить GitHub API rate-limit без токена (для двох джерел раз на 12 год цього досить).
